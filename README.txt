KEYFANK — VS CODE SETUP

Files:
- index.html
- keyfank.css
- keyfank.js

Run:
1. Open this folder in VS Code.
2. Install the "Live Server" extension if needed.
3. Right-click index.html.
4. Choose "Open with Live Server".
5. The browser should open:
   http://127.0.0.1:5500/

Important:
- Keep all three files in the same folder.
- The 3D scene uses Three.js from the CDN, so internet access is required.
